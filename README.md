## Deploy using Vercel

1. Create a **public** GitHub repository, for example `meariell-cv`.
2. Upload the project files or push the local repository with Git.
3. On Vercel, select **Add New → Project**, import the GitHub repository, and deploy. The site is static; no framework or build command is needed. Set the root directory to the repository root.
4. Open the Vercel URL and test navigation, email/GitHub links, profile image, and phone layout.
5. Submit both the live Vercel URL and the GitHub repository URL to the LMS.
